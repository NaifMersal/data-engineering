Data Engineering Track · Bootcamp

Modern Data Engineering

From raw sources to a governed, AI-ready lakehouse: ingest, model, test, scale, stream, orchestrate and govern data with the open tools data teams use today.

4 teaching days × 4 hours · 16 hands-on labs in Python and SQL · capstone day

Schedule

The whole week follows one case: Qafila, a fictional grocery delivery app in Riyadh, Jeddah and Dammam, whose messy sources feed one platform that every lab extends. All data is synthetic, so the labs run offline.

Each session is taught from a 📓 tool notebook (read shows it with outputs) or a 🖥️ slide deck, then practised in a lab. Four sessions a day, with 10′, 20′ and 10′ breaks between them. In the slides, press ? for keys.

Teams present across the four sessions (1–2, 3–5, 6–8, 9–10), then peer feedback, lessons learned and closing.

Capstone

Teams of 2–3 build a working data platform, choosing one of:

  • Qafila Lakehouse: batch and streaming, from raw sources to governed marts and a near-real-time operations view
  • Open Data Platform: Saudi open datasets in a lakehouse with tests, a semantic layer and a small dashboard
  • Real-time Operations Monitor: event-time KPIs, SLA alerts, an Iceberg history table and replay

Minimum: two source types, one command end to end, a layered model with documented grain, idempotent incremental loads, 8+ tests or contract checks, orchestration and a governance note. Starter kit: labs/capstone/.

Rubric

Functional end-to-end pipeline30%
Architecture & data modeling decisions25%
Data quality, testing & observability20%
Orchestration, governance & operability15%
Presentation & reproducibility10%

You will be able to

  • Design a data platform and choose between warehouse, lake and lakehouse
  • Build incremental, idempotent ingestion from databases, APIs, files and CDC feeds
  • Model data dimensionally and transform it with dbt, tested and under contract
  • Work with Iceberg and decide when Spark or streaming is worth it
  • Orchestrate, monitor and govern pipelines under PDPL and NDMO
  • Prepare governed, AI-ready data: semantic layers, embeddings, safe text-to-SQL

Setup

Audience
Developers, analysts and data scientists who know Python and SQL. No Spark, dbt, orchestration or streaming experience needed.
Environment
Google Colab, or any laptop with uv. No Docker or cloud account; Spark needs Java 17+. See labs/README.md.
Tool notebooks
Walked together in class, with no exercises: you practise in the lab after each one. ➕ sections are for your own pace.
