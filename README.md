# Modern Data Engineering

**SDAIA Academy · Data Engineering Track**: a 4-day hands-on bootcamp (4 sessions per day) plus a capstone presentation day. From raw sources to a governed, AI-ready lakehouse: ingest, model, test, scale, stream, orchestrate and govern data with DuckDB, Polars, dlt, dbt, Apache Iceberg, Spark and Dagster.

**Course page and slides:** https://sdaiaacademy.github.io/data-engineering/

| Day | Theme | Sessions |
|---|---|---|
| 1 | Data Platforms, Storage & Ingestion | DuckDB 📓 · files & Parquet 🖥️ · batch ingestion with dlt 📓 · CDC & SCD2 🖥️ |
| 2 | Transformation, Modeling & Quality | bronze → silver with Polars 📓 · dimensional modeling 🖥️ · dbt 📓 · data quality with Pandera 📓 |
| 3 | Lakehouse, Scale & Streaming | Iceberg 📓 · Spark 📓 · streaming fundamentals 🖥️ · streams into the lakehouse 🖥️ |
| 4 | Production: Orchestration, Reliability, Governance & AI | Dagster 📓 · contracts & observability 🖥️ · governance & privacy 🖥️ · data for AI 🖥️ |
| 5 | Capstone Project Presentations | [capstone deck](https://sdaiaacademy.github.io/data-engineering/slides/capstone.html) |

Day 1 opens with the [course introduction](https://sdaiaacademy.github.io/data-engineering/slides/00_intro.html) and the [architecture story](https://sdaiaacademy.github.io/data-engineering/slides/00_story.html): warehouse, lake, lakehouse, the Qafila platform map and one order's journey through it.

Each day runs Session 1 → short break → Session 2 → mid-day break → Session 3 → short break → Session 4. Every session is taught first, then practised in a lab. Break slides (in the concept decks) default to 10 minutes (20 for the mid-day break); the instructor can change the length or type a "back at" time on the slide.

**Slide keys:** `F` fullscreen · `Esc` exit · `←` `→` / `↑` `↓` navigate · `N` speaker notes · `O` overview · `T` start/pause timer · `?` help.

🖥️ Concept sessions have a short deck in `slides/` (for example `D1_4_cdc_scd.html`); 📓 tool sessions are taught from a walkthrough notebook in `labs/tools/`, with no slides (a read-only copy with every output is in `labs/tools/html/`). The course page links each session to what it is taught from, its lab and the solution.

The whole week follows one case study: **Qafila**, a fictional quick-commerce grocery platform in Riyadh, Jeddah and Dammam, with synthetic data generated by `labs/prepare_data.py`.

## Repository

```
index.html          course page (GitHub Pages)
slides/             the course introduction (00_intro.html), the illustrated architecture story (00_story.html),
                    one short deck per concept session (D1_2_…, D1_4_…, …) and the capstone deck
assets/             deck/ (slide engine and logo), story/ (story engine), img/
labs/               notebooks, data generator, dbt project, shared helpers, capstone kit (see labs/README.md)
```

Labs run on any laptop CPU with [uv](https://docs.astral.sh/uv/) or on Google Colab (one click from the course page): see [labs/README.md](labs/README.md).

Add `?check` to a deck's URL to run its layout self-check. It flags overflowing slides and clipped code lines.
